# Personal Portfolio Website - HTML & CSS Internship Project

### Project Description
This personal portfolio website is built entirely with pure HTML5 and CSS3 to showcase technical skills, academic background, and software projects. The site implements semantic HTML tags for document structuring, alongside responsive CSS Grid and Flexbox modules to ensure a flawless experience across mobile, tablet, and desktop viewports. It features an interactive single-page layout with anchored navigation, smooth scrolling, and accessible visual hierarchy.

### Features
- **Pure HTML5 & CSS3:** No external scripts or JS frameworks used.
- **Responsive Layouts:** Mobile-first media queries and flexible Grid/Flexbox containers.
- **Interactive UI:** Smooth transitions, card hover effects, and anchor links.
- **Complete Sections:** Hero, About Me, Skills, Projects, Contact, and Footer.
